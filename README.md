# BABYFACE Whiteboard Ver.2

古いP31タブレットを、ネット接続不要の全画面ホワイトボードとして使うためのAndroidアプリです。

## Ver.2の主な機能
- 全画面ホワイトボード
- 指・スタイラスで手書き
- ペン / 消しゴム切替
- ペン太さ4段階
- Undo / Redo
- 全消去（確認ダイアログ付き）
- 自動保存
- アプリ再起動後の復元
- ステータスバー・ナビゲーションバー非表示
- スリープ防止
- ツールバーは3秒操作がないと自動で隠れる
- 隠れたツールバーは右端の☰ボタンから再表示
- ネットワーク権限なし


## App Icon
The BABYFACE Whiteboard app icon uses the blue circular pen logo.
